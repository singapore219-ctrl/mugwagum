무과금 사냥터

과금 없이 혼자 즐기는 사냥터입니다.
물약 사서 사냥하고, 드랍템 모아서 강화하세요.

휴대폰에서 앱처럼 쓰기

  1. 안드로이드 크롬: 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치
  2. 아이폰 사파리: 아래쪽 공유 버튼 → 홈 화면에 추가
  3. 홈 화면 아이콘으로 켜면 주소창 없이 전체 화면으로 열려요.
  4. 진행 상황은 이 기기 브라우저에 자동 저장돼요. 다른 기기와는 이어지지 않아요.
  5. 사냥터에서 자동 사냥을 켠 채로 화면을 끄거나 나가도, 다시 켜면 그동안 사냥한 결과를 받아요. (최대 12시간, 물약이 있는 만큼)
